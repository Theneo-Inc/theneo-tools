# Theneo Tools Wiki

Welcome to the Theneo Tools documentation. This wiki provides comprehensive documentation for the Theneo CLI and SDK packages.

## What is Theneo?

Theneo is a platform for managing API documentation projects. It allows developers and teams to create, manage, and publish beautiful API documentation with AI-powered description generation.

## What is Theneo Tools?

Theneo Tools is a monorepo containing two npm packages:

| Package | Description | npm |
|---------|-------------|-----|
| **@theneo/cli** | Command-line interface for managing Theneo projects | [npm](https://www.npmjs.com/package/@theneo/cli) |
| **@theneo/sdk** | TypeScript/JavaScript SDK for Theneo API | [npm](https://www.npmjs.com/package/@theneo/sdk) |

## Key Features

### CLI Features
- Create and manage API documentation projects
- Import from OpenAPI specs, Postman collections, or URLs
- AI-powered description generation
- Export/Import documentation in Markdown format
- Multi-workspace support
- Version management
- Publish documentation

### SDK Features
- Full TypeScript support
- Promise-based API with Result types
- Project management (create, delete, publish)
- Documentation import/export
- Workspace management
- Version management
- Postman collection integration

## Requirements

- Node.js >= 18.x
- npm >= 9.x
